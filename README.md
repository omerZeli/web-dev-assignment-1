# Digital Business Card

A personal digital business card built for the first web development
assignment. It presents me to potential employers and gathers my contact
details, background and projects on a single page.

The site is built with **HTML and CSS only** – there is no JavaScript.

## Features

- Profile picture, full name and role
- Short "About Me" paragraph
- Skills section
- Projects section
- Contact links: GitHub, LinkedIn, email and phone
- **Dark / light mode** switch made with pure CSS (a hidden checkbox and
  the `:checked` pseudo-class together with the `~` sibling selector)
- Responsive layout for both mobile and large screens

## Files

- `index.html` – the page structure
- `styles.css` – all of the styling (kept in a separate external file)
- `images/profile.jpg` – the profile picture

## How to view

Just open `index.html` in a web browser, or visit the live version
published with GitHub Pages.
